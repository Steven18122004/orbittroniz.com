
Orbittroniz Games HD — Upload-ready website files
This ZIP is arranged so you can upload the four files directly into your repository's games/ folder. The HTML, stylesheet and JavaScript are at the ZIP root (not buried in another nested folder).
Upload to GitHub / Vercel
Download and extract this ZIP.
Open the GitHub repository connected to orbittroniz.com.
Open or create the games folder in the repository root.
Upload index.html, style.css, and games.js into that games/ folder. Do not upload them into a second folder named orbittroniz-games-hd.
Commit changes and wait for Vercel to finish deploying.
Visit https://orbittroniz.com/games/. If an older version appears, refresh or clear the browser cache.
Included games
Ludo Royale (simplified local pass-and-play prototype)
Neon Snake (keyboard and touch controls)
Tic-Tac-Toe (computer opponent and two-player mode)
Memory Match
2048 (keyboard and swipe controls)
Quality notes
Responsive, higher-contrast dashboard styling, depth and lighting effects, touch-friendly controls and safer game startup. No paid APIs are required. This is polished 2D browser gameplay with CSS 3D-style visuals—not photorealistic 3D. A true HD 3D game needs a 3D engine and 3D models. Google Fonts improves typography when internet access is available; system fallbacks are included.
Troubleshooting
Make sure all three files are in the same games/ folder.
The correct path is games/index.html, games/style.css, and games/games.js.
If you see a blank page, check that the latest Vercel deployment succeeded.
